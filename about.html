About RouteOpt

Algorithmic route optimization — no map API required

RouteOpt is a pure front-end Vehicle Route & Fuel Cost Optimizer. You enter delivery or pickup stops with coordinates; the browser computes a distance matrix using the Haversine formula and builds an efficient visiting order with the Nearest-Neighbor heuristic, optionally improved by 2-opt.

Why no map API?

The core challenge is algorithmic: implement real route-optimization logic yourself instead of calling a commercial routing service. This keeps the project educational, offline-friendly, and free of API keys.

What you can do

  • Add stops (name + latitude / longitude)
  • Set vehicle mileage and fuel price
  • Run optimization and see ordered route + total km + estimated fuel cost
  • Save named stop sets in Local Storage
  • View history and total money spent on the Dashboard
  • Sign up / log in (accounts stored locally in the browser)

Tech stack (syllabus-aligned)

  • HTML5 + CSS3 (dark theme matching the design)
  • Vanilla JavaScript — variables, operators, conditionals, loops
  • Functions, arrow functions, arrays & higher-order methods (map, filter, reduce)
  • Objects, JSON, destructuring, template literals
  • DOM selection & manipulation, events, forms & validation
  • Local Storage for users, stops, sets, and route history

Disclaimer

Distances are straight-line (great-circle) approximations. Real road distances and traffic are not considered. Fuel cost is an estimate based on the numbers you provide.
