The Algorithm

Turning a complex problem into an efficient route.

The Vehicle Routing Problem can become computationally expensive as the number of stops increases. Instead of trying every possible route, RouteOpt uses heuristics to quickly find a practical solution.

Try the Optimizer →
// Simplified flow
route = nearestNeighbor(stops)

while improved:
  improved = false

  for each pair of edges:
    newRoute = twoOptSwap()

    if distance(newRoute)
      < distance(route):

      route = newRoute
      improved = true

return route
